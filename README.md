## Canvas Assignment Scraper

## About

This project uses JavaScript, jQuery, and JSDOM to scrape assignment information from a saved Canvas page.

It displays the results directly in the terminal.

## Information Collected

Assignment Title

Link

Due Date

Status

## Tools Used

Node.js

jQuery

JSDOM

## How to Run

First, install the packages:

npm install


Then run:

node scraper.js

## Note

The project does not use a UI or JSON. All output is shown in the terminal.
